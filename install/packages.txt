# dotfiles-Arch/install/packages.txt
# pacman package names for the modern terminal stack. One per line; # comments ok.
# Arch is the "cleanest distro for this stack": everything below is in the
# official repos (core/extra), INCLUDING starship/atuin/yazi/mise/lazygit — so,
# unlike Fedora, there are NO upstream-installer fallbacks in bootstrap.sh.

# ── shell + multiplexer ───────────────────────────────────────
zsh
tmux

# ── modern CLI core (all in extra) ────────────────────────────
eza            # ls
bat            # cat
fd             # find  (binary is `fd` on Arch — not fdfind as on Debian)
ripgrep        # grep
zoxide         # cd
fzf            # fuzzy finder
git-delta      # git pager / diffs  (binary: delta)
btop           # top/htop
tealdeer       # tldr (fast Rust client; binary: tldr)
dust           # du   (HAVE_DUST in 00-tools.zsh picks it up)
procs          # ps   (HAVE_PROCS in 00-tools.zsh picks it up)
sd             # sed-alternative (nvim-spectre / scripts; parity with the Mac)
duf            # df   (disk-usage/free viewer)
gron           # greppable JSON  (gron | grep | gron -u)
jc             # command output -> JSON (ps/ss/dig | jc --X | jq); core-doctor data / net row
glow           # markdown renderer for the terminal
gum            # charm's shell-script UI toolkit (prompts/spinners/pickers)
xh             # HTTPie-style HTTP client (curl companion)
doggo          # DNS client (now in `extra` — was AUR/go until 2025)
go-yq          # yq — mikefarah's *Go* yq. Binary is `yq`. NOT the Arch `yq`
               # package, which is the unrelated Python jq-for-YAML tool.
# The rest of core-doctor's set is not in the official repos: sesh is go-installed
# best-effort by bootstrap.sh; op (1Password CLI) is AUR-only, so bootstrap just
# prints the paru/install hint rather than installing it. viddy (the watch
# replacement, HAVE_VIDDY-gated) is the same story — a Rust CLI that lives only in
# the AUR, and since we build no AUR helper and install no rust toolchain here,
# bootstrap prints `paru -S viddy` instead of installing it. carapace is a printed
# hint too, but for a stronger reason: `go install` cannot work for ANY version of
# it (replace directives + uncommitted generated sources), and hand-placing the
# upstream binary in ~/.local/bin would shadow a later `paru -S carapace-bin` —
# see bootstrap.sh's carapace block, and core/PORTING-MATRIX.md's carapace footnote ²⁷.
# Native route for all four, if you already run paru:
#   paru -S carapace-bin sesh-bin 1password-cli viddy
# The opt-in Core extras jujutsu/difftastic/ast-grep ARE in `extra` but are left
# out by design — Core gates them on HAVE_JJ/HAVE_DIFFT/HAVE_ASTGREP, so a box
# without them just skips the wiring. `pacman -S jujutsu difftastic ast-grep` to
# enable.

# ── prompt / history / runtime mgr / file mgr (in repos on Arch) ─
starship       # prompt   (Fedora installs this from upstream; Arch packages it)
atuin          # shell history
yazi           # file manager
mise           # polyglot runtime manager (node/python/go/...). `pacman -S mise`
uv             # Astral per-project Python (`.venv` + tool runner). Pairs with mise
               # above: mise owns the GLOBAL interpreter, uv the per-project envs —
               # see core/mise/config.toml. Core probes it (HAVE_UV → uvr/uvs) and
               # core-doctor treats it as REQUIRED, not opt-in: absent, it's a `✗`.
lazygit        # git TUI  (in extra — no COPR needed, unlike Fedora)

# ── editor + git workflow ─────────────────────────────────────
neovim
git            # `git subtree` ships INSIDE this package on Arch — no separate pkg
openssh        # ssh / ssh-keygen / ssh-agent — push via SSH (NOT shipped on minimal Arch)
github-cli     # binary is `gh` — PRs/issues/releases from the terminal. Needs a
               # one-time interactive `gh auth login`; bootstrap can't do that for you.

# ── clipboard ─────────────────────────────────────────────────
wl-clipboard   # wl-copy / wl-paste (Wayland)
xclip          # X11 fallback (sessions / SSH X-forward)

# ── build toolchain (AUR builds, makepkg, native modules) ─────
base-devel     # metapackage — a *package* since 2022, not a group. Its 26 deps
               # ride along on `pacman -Syu`; a group's members would not have.
               # Needed to build an AUR helper (paru/yay).
# NOTE: language runtimes (rust/node/python/...) are owned by mise — see
# core/mise/config.toml. We do NOT install `rust` from pacman here because the
# whole CLI stack above is already packaged, so nothing needs `cargo` to build.

# ── Neovim provider deps (fix :checkhealth) ───────────────────
python-pynvim  # the Python 3 provider module (Arch name; Fedora = python3-neovim)
python-pip     # pip for the system python   (Arch name; Fedora = python3-pip)
tree-sitter-cli # nvim-treesitter (main) compiles parsers locally — needs CLI ≥0.26.1 (extra has 0.26.9)
                # + a C/C++ compiler, which base-devel above already provides.
# rust-analyzer  # uncomment if you use the Rust LSP (rustaceanvim wants it)
# go             # uncomment if you want the Go LSP (gopls) + Go tooling

# ── pacman quality-of-life helpers (used by os/arch.zsh) ──────
pacman-contrib # provides checkupdates, paccache, rankmirrors
reflector      # rank/refresh mirrorlist (run manually; see os/arch.zsh notes)

# ── misc useful ───────────────────────────────────────────────
curl
wget
jq
w3m            # terminal web browser (text-mode; renders tables + inline images)
direnv
gawk
flatpak
